The eight techniques

Each of these has a name because naming it makes it checkable. They are the generative model.

1

The display ramp

72 to 40 to 34 to 32 to 15, one serif at one weight. Hierarchy comes from size alone: not from boxes, not from weight, not from colour, not from rules. A page that is running long breaks instead of shrinking.

2

Light, not fill

The gradient appears as a blurred hero wash, a rising continuation glow, and a one-pixel border on a table. Light passes behind content; fill competes with it.

3

The skeuomorphic triad

Gradient body, white inner shadow at the lit edge, coloured drop shadow in the object's own hue. Two of the three is not a reduced version of the effect, it is a different and wrong effect.

4

The semantic dyad

Coral is open, teal is resolved, and that mapping is fixed. Colour is data, never decoration, never applied to prose. A third state is grey. There is no fourth hue.

5

The hero wash is one smooth field

A single blurred gradient inside a clipping frame, holding exactly one child. A hero carrying a second layer is wrong, and the fix is to delete that layer rather than to tune it.

6

A line is a line

Every rule, divider and row separator is a real line node with a one-pixel hair stroke. Not a one-pixel rectangle, and never a frame with three of four stroke edges zeroed.

7

Prose is never in a box, a token always is

No prose sits in a card, a well, a pill or a tinted panel. A status, a track name or a list numeral is always a chip, because it is a token rather than prose.

8

Extract, never eyeball

Pull a Figma graphic with get_design_context and transcribe the geometry unchanged. Approximating from a screenshot has been rejected every time it has been tried.

The restraint everywhere else is what earns the physical moments. A flat coloured rectangle in a Keeyu document reads as an unfinished version of something, because in this system it is.
