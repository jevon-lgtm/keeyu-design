The fourteen non-negotiables

The enforcement layer. The techniques tell you what to build; these tell you what has repeatedly been built instead.

1

No micro-labels

No tiny uppercase letter-spaced kickers, no 01, no section numbers, no client chrome. The only caps in the document is the wordmark, which is a logo asset.

2

No em dashes

Anywhere. Not in prose, not in layer names. Commas, full stops, colons, or the middle dot.

3

Type hierarchy carries the document

Not boxes. Every body block is one of exactly two shapes: the two-column comparison row, or the single-column prose section block.

4

Containers are for graphics only

The only rounded container is the graphic well at radius 22 and the cards inside it.

5

Every graphic is skeuomorphic

Gradient fill, white inner-shadow highlight, coloured drop-shadow glow. A flat rectangle is not acceptable output.

6

Copy is verbatim

Reproduce supplied sentences exactly. Reformat and re-lay-out freely; do not rewrite, summarise, merge or tighten the words unless asked.

7

Coral means problem, teal means resolved

Never decorative, never reversed, never applied to prose.

8

Do not add what the source does not have

No meta line if the source has none. No customer name on a generic template. No invented headline to cover two sections you felt like merging.

9

A line is a line node

There are no exemptions. A single-edge stroke anywhere in a Keeyu document is a defect. Strokes on a frame are legitimate only when all four edges are visible.

10

Graphics are extracted, never eyeballed

Author at Figma native size and scale the whole module by 0.6403.

11

The wordmark is an asset, never type

Place the SVG. Never set the name in a typeface to stand in for it, never letter-space a sans and call it the logo, never redraw the star.

12

The page ground is #FAFAFA, not white

The sheet, the hero's ground, the hero's fade and the dot grid scrim all carry it. Cards and wells keep their own fills.

13

Every page carries the dot grid

Portrait and landscape. It is not decoration and it is not optional: it is the ground the documents sit on.

14

Use the chip, the box, the tile grid and the two-column list

A status set as plain text, a table with no border, a run-on list of categories, and a numbered list running one full-width column are regressions, not neutral choices.

Several Keeyu artefacts are generic templates, identical across every deal except for one customer-specific list. On those the customer is never named in the body, there is no meta line, and there is no date. The file name carries the customer, the document does not.
